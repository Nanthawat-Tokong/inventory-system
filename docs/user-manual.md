# คู่มือการใช้งาน

> ในระบบมีหน้า **❓ วิธีใช้** (เมนูด้านบน) เนื้อหาเดียวกับคู่มือนี้ และเปิดมาจะเห็นของบทบาทตัวเองก่อน

## เริ่มต้น
1. เปิดเว็บ แล้วเข้าสู่ระบบด้วยอีเมลและรหัสผ่านที่ผู้ดูแลระบบให้มา
2. **ครั้งแรก** ระบบจะให้ตั้งรหัสผ่านใหม่ของตัวเอง (อย่างน้อย 8 ตัวอักษร) — ใช้หน้าอื่นไม่ได้จนกว่าจะตั้ง
3. หน้าแรกมีกล่อง **"งานของคุณ"** บอกว่าตอนนี้ต้องทำอะไร กล่องที่ขอบแดง = มีงานรอ กดแล้วไปหน้านั้นเลย
4. ตัวเลขสีแดงบนเมนู **ใบขอเบิก** = จำนวนใบที่รอคุณ
5. เปลี่ยนรหัสผ่านทีหลัง: กดชื่อตัวเองมุมขวาบน (👤)

## ของเดินทางจากคลังหลักไปสาขา
**สาขาขอเบิก → ผู้จัดการคลังหลักอนุมัติ → พนักงานจัดส่งส่งของ → สาขาตรวจรับ → เสร็จ**
ถ้าของชำรุด/ไม่ครบ สาขาแจ้งตอนตรวจรับ → คลังหลักส่งของแทน หรือตกลงปิดเคสร่วมกัน
ในใบขอเบิกทุกใบมีแถบขั้นตอน (บอกว่าอยู่ขั้นไหน) และ "ไทม์ไลน์ & ข้อความ" (คุยกับอีกฝ่ายได้)

---

## พนักงานสาขา

### ขอเบิกของ
1. เมนู **ใบขอเบิก** → **+ สร้างใบขอเบิกใหม่** (หรือกล่อง "ขอเบิกของ" ที่หน้าแรก)
2. พิมพ์ชื่อสินค้า/รหัสในช่องค้นหา แล้วเลือก — **จะเห็นเฉพาะของที่คลังหลักมีให้เบิก**
3. ใส่จำนวน (ไม่เกินช่อง "เบิกได้") ต้องการหลายอย่างกด **+ เพิ่มรายการสินค้า**
4. กด **ส่งใบขอเบิก** — รอผู้จัดการอนุมัติ

### ตรวจรับของ
1. ของมาถึง → หน้าแรกขึ้นกล่อง "ของมาถึงแล้ว รอตรวจรับ" → เปิดใบนั้น
2. นับของทีละรายการ: ช่อง **สภาพดี** = ใช้ได้, ช่อง **ชำรุด/บกพร่อง** = เสีย — ที่เหลือระบบคิดเป็น "ขาด" ให้
3. ครบและดีทุกชิ้น → **ยืนยันรับครบถ้วน** / มีปัญหา → เขียนอธิบาย → **ยืนยันรับ + แจ้งปัญหาไปคลังหลัก**
4. ของสภาพดีเข้าสต๊อกสาขาทันที, ของชำรุด **เก็บไว้ก่อน** รอคลังหลักบอกว่าทิ้งหรือส่งคืน

### เมื่อมีปัญหา
- ติดตามในใบนั้น — คลังหลักจะตอบว่า "กำลังจัดส่งใหม่" หรือ "สต๊อกยังไม่พอ"
- ของชดเชยมาถึง → ตรวจรับในส่วน "การจัดส่งชดเชย" — ได้ครบแล้วใบปิดเอง
- คลังหลัก "ขอปิดเคส" → อ่านเหตุผล → **ยอมรับ ปิดเคส** หรือพิมพ์เหตุผลแล้ว **ยังไม่ยอมรับ**

### บันทึกของออก (ขาย / ใช้ / เสียหาย)
เมนู **รับ/ออกสินค้า** → เลือกสินค้า → ใส่จำนวน + หมายเหตุ → **บันทึก**

### ดูว่าเบิกอะไรไปแล้ว ยังรออะไร
เมนู **รายงาน** → แท็บ **การเบิกของฉัน** (หรือกล่อง "ของที่ฉันเบิก" ที่หน้าแรก)

---

## ผู้จัดการคลังหลัก (ผู้อนุมัติ)

### อนุมัติใบขอเบิก
1. หน้าแรก "ใบขอเบิกรออนุมัติ" → เปิดใบ
2. ตารางบอกแต่ละรายการ: ขอเท่าไร, คลัง **เบิกได้** เท่าไร, ป้าย **พอ / ไม่พอ / ไม่มีของ**
3. แก้จำนวนอนุมัติได้ (ไม่เกินที่เบิกได้ — ระบบใส่ค่าที่ส่งได้จริงไว้ให้แล้ว) → **อนุมัติ** → งานไปที่พนักงานจัดส่ง
4. ไม่ให้เบิก → **ปฏิเสธ** + เหตุผล
5. อนุมัติผิด → เปิดใบ → **ยกเลิกการอนุมัติ** (ได้ก่อนพนักงานจัดส่งกดส่ง)

### เมื่อสาขาแจ้งปัญหา (ต้องตอบทุกครั้ง)
- ① มีของ → ใส่จำนวนส่งชดเชย → **เตรียมส่งใหม่** (พนักงานจัดส่งจะส่ง)
- ② ไม่มีของ → พิมพ์บอก → **แจ้งสต๊อกยังไม่พอ**
- ของชำรุด → ส่วน "ของชำรุด — จัดการอย่างไร" ใส่จำนวน **ตัดทิ้ง** / **ส่งคืนคลัง** → บันทึก · ของคืนมาถึงกด **ได้รับคืนแล้ว**
- ③ ตกลงกันได้ → **ขอปิดเคส** + ข้อสรุป (สาขาต้องกดยอมรับ)

### รับของเข้าคลัง / ดูว่าควรสั่งอะไร
- เมนู **รับ/ออกสินค้า** → ประเภท "รับเข้า" → เลือกสินค้า + จำนวน → บันทึก
- เมนู **รายงาน** → แท็บ **ควรสั่งเพิ่ม**

### ตั้งค่า
- **ตั้งค่าแจ้งเตือน:** เกณฑ์ขั้นต่ำเฉพาะสาขา (ถ้าไม่ตั้งใช้ค่ากลางของสินค้า)
- **สินค้าประจำสาขา:** เปิด/ปิดสินค้าที่แต่ละสาขาเห็นและขอเบิกได้

---

## พนักงานจัดส่ง
1. หน้าแรก "ใบขอเบิกรอจัดส่ง" → เปิดใบ
2. จัดของตามคอลัมน์ **จะส่งได้**
3. ใส่หมายเหตุ (ทะเบียนรถ / คนขับ) → **ยืนยันจัดส่ง** — ระบบตัดสต๊อกคลังหลักและแจ้งสาขา
4. ของชดเชย: กล่อง "ของชดเชยรอส่ง" → เปิดใบ → ส่วน "การจัดส่งชดเชย" → **ยืนยันจัดส่งของชดเชย**
5. ของชำรุดที่สาขาส่งคืนมาถึงคลัง → กด **ได้รับคืนแล้ว**

## ผู้ดูแลระบบ (admin)
- **ผู้ใช้งาน:** เพิ่มผู้ใช้ (ตั้งรหัสชั่วคราว — ผู้ใช้ต้องเปลี่ยนเองตอนเข้าครั้งแรก), ลืมรหัส = แก้ผู้ใช้แล้วใส่รหัสใหม่
  - ลบผู้ใช้ที่เคยทำรายการไม่ได้ (ประวัติจะหาย) → ให้เปลี่ยนรหัส/บทบาทแทน
  - พนักงานจัดส่งต้องสังกัดสาขาคลังหลัก
- **สาขา:** เพิ่ม/แก้/ซ่อนสาขา, ย้ายคลังหลัก (ติ๊กที่สาขาใหม่ — ระบบถามยืนยัน)
- **สำรองข้อมูล:** ดู README หัวข้อ "สำรองข้อมูล"

## รายงาน (เมนู รายงาน)
เลือกช่วงวันที่ (ปุ่มลัด วันนี้ / สัปดาห์นี้ / 7–90 วัน / เดือนนี้ / เดือนก่อน) และสาขา แล้วเลือกแท็บ:

| แท็บ | ใช้ดู |
|---|---|
| ภาพรวม | ยอดรับ/ออก, กราฟรายวัน, สถานะสต๊อก, ใบขอเบิก |
| รายวัน / รายสัปดาห์ / รายเดือน | สรุปตามช่วงเวลา กดแถวเพื่อดูว่าสินค้าอะไรเคลื่อนไหว |
| ความเคลื่อนไหวสต๊อก | ยกมา → รับ → ออก → คงเหลือ ต่อสินค้า |
| ออกมาก / ค้างสต๊อก | ของขายดี และของที่ไม่เคลื่อนไหว |
| ควรสั่งเพิ่ม | ของใกล้หมด + จำนวนที่แนะนำ |
| ใบขอเบิก | ได้ของครบกี่ %, ของชำรุด, ใช้เวลานานแค่ไหน |
| การเบิกรายคน | ใครเบิกอะไร ได้แล้ว / ยังรอ |
